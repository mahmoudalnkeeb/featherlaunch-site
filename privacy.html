Privacy Policy

Effective October 25, 2026

FeatherLaunch is a free desktop launcher for Minecraft: Java Edition, made by an independent developer (mahmoudalnkeeb). This policy explains what data the launcher handles and where it goes. The short version: FeatherLaunch has no servers of its own, collects nothing, and keeps your data on your computer. It talks only to the services needed to sign you in, download the game and install mods.

What we collect

Nothing. FeatherLaunch has no accounts of its own, no analytics, no telemetry, no crash reporting and no advertising. The developer never receives your sign-in, your game data or information about how you use the launcher.

What stays on your computer

The launcher stores the following locally, in its data folder (%APPDATA%\featherlaunch on Windows, ~/.config/featherlaunch on Linux, or a data folder next to the program in portable mode):

  • Accounts: your Minecraft username, profile UUID and skin address.
  • Settings: memory, Java and launcher preferences.
  • Instances: your game folders, worlds, mods, resource packs, screenshots and logs.
  • Caches: downloaded game files, Java runtimes, mod icons and skins.

Your Microsoft sign-in is kept as a refresh token in your operating system's secure credential store: Windows Credential Manager, or the Secret Service (GNOME Keyring, KWallet) on Linux. It is never written to the launcher's files. Minecraft access tokens are kept only in memory while the launcher runs, and are hidden from the game log shown in the launcher. Removing an account deletes its stored credential. Deleting the data folder removes everything else.

How sign-in works

FeatherLaunch uses Microsoft's device code sign-in. You enter a short code on Microsoft's own website, so the launcher never sees your password. After you approve it, the launcher uses Xbox Live and Minecraft services to confirm that your account owns Minecraft: Java Edition, read your username, UUID and skin, start the game as you, and change your skin when you ask it to. Offline accounts send nothing anywhere.

Services the launcher connects to

To work, FeatherLaunch sends requests directly from your computer to these services. Each one sees your IP address and the request, and handles it under its own privacy policy.

ServiceWhat is sentWhy
Microsoft and Xbox LiveSign-in codes and tokens for your accountSigning you in (device code, Xbox Live, XSTS)
Minecraft services (Mojang)Your access token; a skin image if you upload oneChecking ownership, reading your profile, changing your skin
Mojang download serversRequests for game filesDownloading Minecraft, libraries and assets
ModrinthSearch terms, Minecraft version and loader; file hashes of installed modsBrowsing and installing mods and modpacks, checking for updates, showing names and icons
Fabric, Quilt, Forge and NeoForgeRequests for loader versions and filesInstalling mod loaders
Eclipse Adoptium (and GitHub, which hosts its files)Requests for a Java runtimeDownloading Java when none is installed
Modpack file hostsRequests for the files a modpack listsInstalling a modpack you chose

Requests identify the launcher by name and version (its user agent). They do not include an ID that tracks you between sessions. When you start the game, Minecraft itself connects to Mojang and to any servers you join, as it does with any launcher.

Their policies: Microsoft (which also covers Xbox Live and Mojang), Modrinth, Eclipse Foundation and GitHub.

This website

This site is a static page hosted on GitHub Pages. It sets no cookies and runs no analytics or trackers. GitHub may log visits (such as IP addresses) to operate and secure the service, as described in its privacy statement.

Children

FeatherLaunch does not collect personal information from anyone, including children. Microsoft account and Minecraft age rules still apply to signing in.

Your choices

  • Remove an account in the launcher to delete its stored sign-in.
  • Delete the data folder to remove all local launcher data.
  • To review or delete data held by Microsoft, Mojang or Modrinth, use their account and privacy tools; FeatherLaunch cannot access it.

Changes to this policy

If the launcher starts handling data differently, this page will be updated first and the date at the top will change.
