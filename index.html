FeatherLaunch

A lightweight Minecraft: Java Edition launcher for low-end Windows PCs, written in Rust.

What it is

FeatherLaunch is a free, independent desktop launcher. It lets players sign in with their own Microsoft account, manage several game installations, and add mods from Modrinth, while using as little memory and CPU as possible so older computers have more left over for the game.

Features

InstancesSeparate game folders, each with its own version, memory and Java settings.
Mod loadersVanilla, Fabric, Quilt, Forge and NeoForge.
ModrinthInstall mods, resource packs, shaders and modpacks, with dependencies and updates.
Microsoft sign-inStays signed in. Shows your skin and lets you change it.
Automatic JavaFinds or downloads the right Java for each Minecraft version.
Game consoleLive logs, crash reports and a stop button.

How sign-in works

FeatherLaunch uses Microsoft's standard device code sign-in. The launcher shows a short code, and you enter it on Microsoft's own website in your browser. The launcher never sees your password. After sign-in it uses Xbox Live and the Minecraft services API only to:

  • confirm that your account owns Minecraft: Java Edition,
  • read your Minecraft username, UUID and skin,
  • start the game as you, and change your skin when you ask it to.

Privacy

  • No accounts, analytics or telemetry. FeatherLaunch has no servers of its own and collects no data.
  • Your Microsoft sign-in (refresh token) is stored only on your computer, in Windows Credential Manager. Minecraft access tokens are kept in memory only.
  • Removing an account in the launcher deletes its stored credential.
  • The launcher connects only to the services it needs: Microsoft / Xbox Live and Mojang (sign-in, game files), Modrinth (mods), Eclipse Adoptium (Java), and the Fabric, Quilt, Forge and NeoForge download servers.
