Spec sheet

Built around old hardware

Written in Rust with no web browser inside, and tested on the kind of PC it's made for.

~50 MB

~0%
Windows download
7.8 MB

6.8 MB

Measured on Windows with an Intel Core i7-4790S and Intel HD 4600 graphics.

Rests when idle

It only redraws when something changes.

Old graphics welcome

Uses OpenGL that old integrated graphics handle.

No double downloads

Instances share game files.

Out of the way

Minimizes while you play, with Java settings tuned for slower CPUs.

Everything else

The rest of the toolbox

Mod loaders

Fabric, Quilt, Forge and NeoForge are installed for you. Vanilla works too.

Java, handled

The right Java for each Minecraft version is found on your PC or downloaded for you.

Worlds and servers

Copy, rename and import worlds, manage data packs, and join a server with one button.

Backups and sharing

Export an instance as a zip, or share it as a .mrpack.

Portable mode

Add an empty portable.txt and everything stays in one folder, such as on a USB stick.

Logs that help

A live log with saved crash reports, and one-click upload to share with someone helping you.

Linux extras

GameMode, MangoHud, the discrete GPU, and the system's GLFW and OpenAL.

Shortcuts and command line

Start an instance from your desktop, or join a server with --launch and --server.

Discord presence

Show what you're playing on your profile. Off until you turn it on.

Switching

Coming from Prism or MultiMC?

Point FeatherLaunch at your old launcher's folder and your instances come with you. Your old launcher's files are only read, so you can try it with nothing to lose.

Questions

Before you download

Is FeatherLaunch free?

Yes, and it's open source under the GPL-3.0 license. You still need to own Minecraft: Java Edition.

Can I play without buying Minecraft?

No. Offline play also needs a signed-in Microsoft account that owns the game.

Which Minecraft versions and mod loaders work?

Releases and snapshots, plus alpha and beta versions, with Fabric, Quilt, Forge and NeoForge. Java downloads automatically.

Is there a macOS version?

No. FeatherLaunch runs on 64-bit Windows and Linux, on PCs with OpenGL graphics.

Does it support CurseForge?

Not yet. You can add CurseForge mods by hand with Add files, but CurseForge pack zips can't be imported. Modrinth is built in.

Is it official?

No. It isn't approved by or associated with Mojang or Microsoft.
