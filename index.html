Features

Everything you need, nothing you don't

FeatherLaunch covers what players use launchers like Prism for, in a quiet game-library interface that keeps memory and CPU free for Minecraft.

Instances

Separate game folders with their own version, memory, Java and icon. Group, search, duplicate and track play time.

Mod loaders

Vanilla, Fabric, Quilt, Forge and NeoForge, installed for you.

Modrinth

Browse mods, resource packs and shaders with icons. Install with dependencies, update, enable or disable.

Modpacks

Install Modrinth modpacks in one click, or import a .mrpack file. The pack's icon comes along.

Microsoft sign-in

Sign in with the Microsoft account that owns Minecraft. Stays signed in, shows your skin and lets you change it.

Automatic Java

Finds or downloads the right Java for each Minecraft version.

Game log

Live logs with filtering, crash reports and a stop button, right on the instance page.

Portable

One small program, no installer: an .exe on Windows, a single binary on Linux. Can run from a USB stick.

Mods

Your mods, at a glance

Every instance has its own page for settings, mods, resource packs, shaders, worlds and the game log. Mods show their real names and icons, even ones you added by hand, and can be switched off without deleting them.

Built for slow PCs

Light by design

  • Uses about 50 MB of RAM, and the program itself is about 6 MB. Fonts come from the system and icons are drawn in code, so nothing extra is bundled.
  • Draws only when something changes. It sits at almost 0% CPU while idle.
  • Runs on old integrated graphics such as Intel HD 4000/4600. OpenGL, no shadows, no animation loops.
  • Game files and icons are shared between instances and cached. Nothing downloads twice.
  • Minimizes itself while you play. Java memory settings are tuned for low-end CPUs.

Sign-in

How sign-in works

FeatherLaunch uses Microsoft's standard device code sign-in. The launcher shows a short code, and you enter it on Microsoft's own website in your browser. The launcher never sees your password.

After sign-in it uses Xbox Live and the Minecraft services API only to confirm that your account owns Minecraft: Java Edition, read your Minecraft username, UUID and skin, start the game as you, and change your skin when you ask it to.

Privacy

Your data stays on your PC

  • No accounts, analytics or telemetry. FeatherLaunch has no servers of its own and collects no data.
  • Your Microsoft sign-in (refresh token) is stored only on your computer, in Windows Credential Manager, or on Linux in your desktop's keyring (GNOME Keyring, KWallet). Minecraft access tokens are kept in memory only.
  • Removing an account in the launcher deletes its stored credential.
  • The launcher connects only to the services it needs: Microsoft / Xbox Live and Mojang (sign-in, game files), Modrinth (mods), Eclipse Adoptium (Java), and the Fabric, Quilt, Forge and NeoForge download servers.
